## ⚡ Démarrage Rapide

```bash
# 1. Installation des dépendances
npm install

# 2. Lancement en mode Web (Vite)
npm run dev

# 3. Lancement en mode Bureau (Tauri)
npm run tauri dev

# 4. Compilation APK Android (Tauri)
npx @tauri-apps/cli android build -- --apk
```
